Visão Técnica do Projeto

Escopo e Ferramentas

Projeto estruturado para um ciclo de desenvolvimento rápido (1 semana), priorizando a fundação mecânica sobre a complexidade visual, ideal para demonstração de portfólio técnico.

  • Engine: Unity 2D (C#)
  • Design Pattern: Orientação a Objetos, Object Pooling
  • Plataforma-Alvo: PC / WebGL / Mobile
  • Persistência: PlayerPrefs para armazenamento local de high-scores.

Core Mechanics

Lógica de jogo implementada utilizando a física nativa da Unity e manipulação de Transforms para eficiência.

  • Movimentação Parallax: Cenário contínuo otimizado para simular velocidade e progressão constante.
  • Controles Físicos: Interações baseadas em `Rigidbody2D` e `BoxCollider2D` para pulos e manobras de agachamento.
  • Spawn Procedural: Geração randômica de obstáculos gerenciada via rotinas padronizadas e otimização de memória.
  • Curva de Dificuldade: Escalonamento matemático global que aumenta a velocidade a cada 15 segundos.
