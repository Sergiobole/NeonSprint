Protótipo: Endless Runner 2D

Um estudo de caso em Unity 2D focado em arquitetura escalável, controles responsivos e execução ágil sob a ótica da programação orientada a objetos.

Acompanhar Progresso Repositório GitHub

O Projeto

Por que este protótipo foi desenvolvido?

Objetivo

Demonstrar capacidade técnica de entregar um ciclo completo de jogo (*Core Loop*) polido em um curto período (1 semana).

Abordagem

Priorização da fundação mecânica e da estrutura de código em C# sobre a complexidade visual e criação de assets.

Resultado

Um Endless Runner funcional, livre de bugs de colisão, com curva de dificuldade matemática e sistema de salvamento nativo.

Arquitetura & Ferramentas

Padrões de projeto e tecnologias utilizadas

Stack & Engine

  • Engine: Unity 2022/2023 (Pipeline 2D)
  • Linguagem: C# moderno
  • Plataformas-Alvo: PC, WebGL (Browser) e Mobile
  • Persistência de Dados: Implementação do `PlayerPrefs` para *High-Scores* locais.

Design Patterns em C#

  • Object Pooling: Reutilização de prefabs (obstáculos) para evitar pico de uso do *Garbage Collector*.
  • Singletons: Gerenciamento centralizado de *GameManager* e sistema de áudio/UI.
  • Component-Based: Separação estrita de responsabilidades (ex: `PlayerMovement`, `PlayerCollision`, `ScoreManager`).

Core Mechanics

Como as interações físicas foram implementadas

Movimentação & Física

Lógica desenhada para garantir a melhor "sensação" (*game feel*) ao jogador.

  • Cenário Parallax: Otimizado via manipulação de `Transform` e texturas em repetição (`Wrap Mode`).
  • Pulo (Jump): Cálculo híbrido usando `Rigidbody2D.AddForce` com multiplicadores para quedas mais rápidas.
  • Hitboxes Dinâmicas: Redução do `BoxCollider2D` via código durante o estado de "agachamento".

Sistemas de Jogo

Regras e progressão gerenciadas autonomamente.

  • Spawn Procedural: Rotinas (`Coroutines`) que variam o intervalo e o tipo de obstáculo baseado no tempo de vida.
  • Escalonamento (Scaling): Variável global de `Time.timeScale` ou multiplicador de velocidade que aumenta gradativamente.
  • Game Over State: Congelamento imediato de interações e exibição assíncrona de painéis de UI (`Canvas`).
